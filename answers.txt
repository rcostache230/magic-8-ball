# Magic 8 Ball answers. One per line:   kind [mood] | line 1 | line 2 | line 3
#
# Three modes (double-tap the screen to switch):
#   ORACLE   common (blue), rare (purple), legendary (gold), glitch (blue + glitch effect),
#            secret:<egg> (only via an easter egg: hard, spam, night)
#   CLASSIC  classic (the traditional 20, blue, no rarity)
#   ROAST    roast (red, "ROASTED" tag, rimshot), roast:<egg> (hard, spam, night)
#   mode:<oracle|classic|roast>  the card shown when switching to that mode
#   skill    the SKILL ISSUE special (any mode): only by swiping up (see README)
#   rickrolled  the card after the rickroll clip (Roast mode: swipe down, then shake)
#
# mood (yes, no or maybe) is required for common, rare, legendary, glitch, classic and
# roast: swiping left rigs the next answer to a "yes" of the current mode, right to a "no".
# Eggs can have several variants; each egg has a cooldown so it can't repeat back to back.
#
# Lines are drawn inside a point-down triangle, so each line must be narrower than the one
# above it. tools/make_assets.py checks the fit and refuses answers that don't fit.
# Allowed characters: A-Z 0-9 space ! ' ( ) + , - . / : ? % É …
#
# After editing:  python3 tools/make_assets.py   then   esphome run magic-8-ball.yaml
